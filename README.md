# Korean Teaching Job Collector

한국어학당, 한국어교원, 한국어 강사 관련 채용정보(국내·해외)를 수집해 SQLite DB에 저장하는 수집 엔진입니다.

## 빠른 실행

```powershell
python collect_jobs.py --sample
```

샘플 HTML을 읽어 `jobs.sqlite3`에 공고를 저장합니다.

실제 출처를 수집하려면 네트워크 접근이 가능한 환경에서 실행합니다.

```powershell
python collect_jobs.py
```

테스트:

```powershell
python -m unittest discover -s tests
```

## 출처 정책

이 데이터는 광고가 붙는 공개 사이트에 쓰일 예정이라, 출처는 다음 기준으로 고릅니다.

- **원래 공고를 낸 기관과 공공 게시판을 우선**합니다 (국립국어원, 세종학당재단, 누리 세종학당, 국제한국어교육학회, 대학 공지, 다누리).
- **로그인 장벽을 우회하지 않습니다.** 회원 전용 페이지는 수집하지 않습니다.
- **다른 회사가 모아 둔 채용 DB를 다시 모으지 않습니다** (상업 채용포털·재게시 사이트).
- 공개 사이트에는 정리한 공고 본문(`body_text`)과 첨부파일 사본을 싣고, 출처·원문 링크는 노출하지 않습니다. `raw_text`는 내부 파싱용입니다.

`monitor_sources.json`의 `retired_sources`에 중단한 출처와 이유가 적혀 있습니다. 실행할 때마다 이 출처들에서 예전에 저장된 공고를 DB에서 지웁니다(`removed N jobs from retired sources`).

| 중단한 출처 | 이유 |
| --- | --- |
| 하이브레인넷 | 상세 공고가 회원 전용. 로그인 수집은 이용약관·DB 권리 침해 소지 |
| 해커스학점은행 | 목록이 로그인 전용이라 게시글 번호를 순차 탐색하던 방식. 경쟁사이기도 함 |
| 잡코리아, 인크루트 | 상업 채용포털의 DB 재수집 |
| 사람인 (웹 페이지) | 공고 DB가 사업 자산인 상업 포털. **공식 오픈API(`SARAMIN_ACCESS_KEY`)로만** 수집 |

`seed_urls.txt`에서 이 출처들의 줄은 `# retired …`로 주석 처리했습니다.

**진학프로는 다시 켰습니다.** 처음에는 재게시 사이트로 보고 껐지만, 실제로는 대학이 지원서를 받으려고 **직접 공고를 올리는 접수 시스템**입니다(연세대, 이화여대, 충남대, 경북대, 가천대 등의 한국어 강사 공고가 여기에만 있음). robots.txt가 `/recruit/` 공고 페이지를 허용하고 사이트맵도 공개합니다. 우리 사이트는 요약과 원문 링크만 보여 주고 지원은 진학프로로 보냅니다.

**한국어교육바다(KLEOcean)**는 한국어교육 커뮤니티의 재게시 게시판이지만, 현재 해외 공고를 얻을 수 있는 거의 유일한 출처라서 유지합니다. 해외 대학 공식 채용 페이지를 직접 수집하는 출처로 대체하는 것을 권장합니다.

## 수집 동작

기본 실행은 오늘 기준으로 접수 기간이 유효한 공고만 저장합니다.

- 마감일이 지난 공고는 저장하지 않고, DB에 남은 것도 실행 시작과 끝에 정리합니다.
- **마감일을 읽지 못한 공고는 버리지 않고** 게시일(없으면 처음 본 날)로부터 45일간 검토 대상으로 둡니다(`UNDATED_GRACE_DAYS`). 해외 공고는 마감일이 영어·일본어로 적혀 있거나 아예 없는 경우가 많아, 예전처럼 버리면 대부분 사라졌습니다.
- 마감일 파싱은 한국어(`접수기간 … ~ …`, `마감일 :`), 영어(`Application deadline: November 15, 2026`, `Review of applications will begin on December 1`, `Next review date: Monday, Nov 2, 2026`), 일본어·중국어(`応募締切 2026年11月30日`, `截止日期`)를 읽습니다. `until the position is filled`와 `채용 시까지`는 상시모집(`rolling`)입니다.
- 날짜 앞에 `~`만 있는 경우는 바로 앞 문맥이 접수·모집·지원·제출일 때만 마감일로 봅니다.

지난 공고까지 포함해 조사하려면 명시적으로 옵션을 켭니다.

```powershell
python collect_jobs.py --include-expired
```

같은 호스트에는 요청 사이에 최소 1초 간격을 둡니다(`MIN_REQUEST_INTERVAL`). 인증서 체인이 불완전한 대학 사이트는 검증 없이 다시 요청하되, `warning: TLS verification skipped for …`를 남깁니다.

누리 세종학당 한국어 교원 모집 목록은 최대 126페이지까지 확인할 수 있습니다. 한 페이지 전체가 지난 공고이면 더 오래된 페이지는 자동으로 멈춥니다.

```powershell
python collect_jobs.py --nuri-pages 20
```

`seed_urls.txt`에 찾은 채용공고 URL을 추가하면 상세 페이지를 직접 수집합니다. 한 줄은 상세 페이지 URL 1개당 공고 1건입니다 — 목록을 순회하며 새 공고를 찾아주지 않습니다. 이미 DB에 저장된 URL은 다시 요청하지 않습니다.

기존에 저장된 공고는 실행마다 `original_url`을 다시 불러와 마감일 연장·조기 마감 여부를 갱신합니다(`refresh_existing_jobs`). 제목·기관·지역은 건드리지 않고 마감일과 본문만 새로고침하며, `rejected` 상태인 공고는 제외합니다. `--no-refresh`로 끌 수 있습니다.

```csv
url,source_name,confidence_score,kind,title_hint,institution_hint,location_hint,deadline_hint
```

### 자동 탐색 출처 (`monitor_sources.json`)

- `kteacher_list`: 국립국어원 한국어교원 구인정보처럼 목록이 로그인 없이 열리는 게시판. 페이지 단위로 순회하며 지난 공고만 있는 페이지에서 멈춥니다. `국외` 분류는 해외 공고로 들어옵니다.
- `iakle_list`: 국제한국어교육학회 게시판(POST AJAX 전용).
- `generic_links` (또는 `kind` 생략): 페이지의 `<a>` 링크 중 관련 있어 보이는 것만 골라 상세 페이지를 엽니다. `url`에 `{page}`를 넣으면 `pages` 수만큼 순회하고, 연속 3페이지가 0건이면 멈춥니다. 게시판 자기 자신을 가리키는 링크(필터 탭·페이지 이동)는 건너뛰지만, `?uid=`, `?articleNo=`처럼 글 번호가 붙은 링크는 공고로 봅니다. 링크 글에 **강사·교원·교사·교수·튜터 같은 가르치는 역할**이 있어야 하고, 첨부파일 링크는 버립니다.
  - 대학 전체 공지 게시판은 게시판 자체 검색을 주소에 넣어 "한국어" 글만 가져옵니다. K2Web 게시판 `artclList.do?srchColumn=sj&srchWrd=…`, 그누보드 `board.php?…&sfl=wr_subject&stx=…`, 영남대식 `?mode=list&srSearchKey=article_title&srSearchVal=…`.
- `goe_recruit`: 경기도교육청 구인구직. 목록이 POST 검색에만 응답해서 `terms`의 검색어(한국어, 다문화, 한국어학급)마다 검색합니다. 이런 공고는 2~3월, 8~9월에 몰립니다.
- `jinhakpro_sitemap`: 진학프로 사이트맵의 공고를 최신 번호부터 열어, **그 공고 제목**에 "한국어"와 가르치는 역할이 있으면 수집합니다(본문 옆에 다른 공고 목록이 붙어 있어 본문으로는 판단하지 않음). 한 번 실행에 `pages`개까지 열고, 관련 없는 공고는 `closed_urls`에 기억해 다시 열지 않으므로 처음 몇 번 이후에는 새 공고만 엽니다.
- 마감됐거나 관련 없는 것으로 확인한 글은 `closed_urls` 테이블에 기억해 다음 실행부터 다시 열지 않습니다.
- `hackers_mobile_probe`, `jobkorea_mobile_list`: 코드는 남아 있지만 현재 쓰는 출처가 없습니다.

### 위치·기관명

- **위치**는 페이지 푸터(사이트 운영사 주소)를 잘라낸 뒤, `근무지/근무지역/소재지` 같은 항목을 먼저 보고, 다음으로 `주소`, 시·도 정식 명칭, 단독으로 쓰인 지역명 순으로 찾습니다. `경기도 광주시`는 `광주`가 아니라 `경기`입니다. `세종학당`, `서울대학교`, `해외여행에 결격사유` 같은 단어는 지역으로 보지 않습니다.
- **기관명**을 못 찾으면 출처 이름으로 대신하지 않고 비워 둡니다(예전에는 `하이브레인넷 한국어 채용검색`이 기관명으로 들어가 지도에 하이브레인넷 사무실이 찍혔습니다). 제목의 `[기관명]`을 대신 쓰되 `[공고]`, `[홍보]` 같은 말머리는 건너뜁니다.

### 중복 공고

같은 공고가 여러 게시판에 올라오면 **기관명 핵심(예: `아주대학교`) + 같은 마감일**로 묶습니다(`assign_duplicate_groups`). 행은 지우지 않고 `duplicate_group_id`를 같게 하고, 그중 하나만 `is_canonical = 1`입니다(승인된 행 → 신뢰도 높은 출처 → 먼저 본 행 순). 공개 사이트는 `is_canonical = 1`만 보여 주면 됩니다.

다시 수집된 공고는 검토 상태(`status`, `review_note`, `reviewed_at`)와 `first_seen_at`을 그대로 유지합니다.

## 구조화 필드 (`extract_fields.py`)

수집이 끝나면 공고마다 다음 필드를 채웁니다.

| 필드 | 예 |
| --- | --- |
| `institution_type` | `university`, `overseas_university`, `sejong`, `multicultural`, `kiip`, `school`, `academy`, `online`, `government`, `other` |
| `country`, `is_overseas` | `미국`, `1` |
| `qualification` | `한국어교원 2급 이상` |
| `experience_required` | `경력 1년 이상` |
| `newcomer_ok` | `1` 신입 가능 / `0` 경력 필요 / `NULL` 언급 없음 |
| `demo_lesson` | `1` 모의수업 있음 / `NULL` 언급 없음 |
| `salary_text` | `시간당 35,000원` |
| `benefits` | 해외 공고의 `항공권, 숙소, 비자` |
| `summary` | 원문을 베끼지 않은 요약 |

기본은 **정규식 규칙**(무료)으로 채웁니다. 요약은 사실 정보를 이어 붙인 한 줄입니다.

`--llm-fields`를 켜면 아직 규칙으로만 채워진 공고를 Claude로 보내 빈 필드를 채우고, 원문을 베끼지 않은 2~3문장 요약을 만듭니다. 공고마다 한 번만 보내고, 실행당 최대 `--llm-limit`건(기본 50)입니다.

**기본은 Claude Code(`--llm-backend claude-code`)**입니다. API 키 없이, 이 컴퓨터에 로그인된 Claude Code 계정으로 `claude -p`(헤드리스 모드)를 공고마다 한 번 실행합니다. 사용량은 Claude Code 요금제 한도에서 차감됩니다.

```powershell
claude          # 처음 한 번: 로그인 확인 (/login)
python collect_jobs.py --llm-fields --llm-limit 20
```

- 도구는 모두 끈 상태(`--tools ""`)로 실행해서 Claude는 공고 텍스트만 읽습니다. 응답은 `--json-schema`로 검증된 `structured_output`만 씁니다.
- 프로젝트 설정이 끼어들지 않도록 임시 폴더에서 실행하고, 세션 기록은 남기지 않습니다(`--no-session-persistence`).
- 로그인이 안 됐거나 사용량 한도에 걸리면 그 자리에서 멈추고, 나머지 공고는 규칙 결과를 그대로 둡니다.
- 모델은 Claude Code에 설정된 기본 모델을 따릅니다.

API 키로 돌리려면 `--llm-backend api`를 씁니다(`pip install anthropic`, `secrets.env`에 `ANTHROPIC_API_KEY`). 이 경우 모델은 `claude-opus-5-5`이고, 안전 분류기가 거절하면 서버가 다른 모델로 다시 시도하도록 `fallbacks: "default"`를 켜 두었습니다.

## 주요 파일

- `collect_jobs.py`: 수집 CLI
- `extract_fields.py`: 구조화 필드 추출(규칙 + 선택적 Claude)
- `review_ui.py`: 수집된 공고를 확인하는 로컬 UI 서버
- `ui/`: 검토 UI 정적 파일
- `build_site.py`, `site_static/`: 공개 정적 사이트 빌더와 그 CSS·JS (결과물 `site/`는 gitignore)
- `tests/`: 파서·DB 규칙·사이트 빌더 회귀 테스트 (`python -m unittest discover -s tests`)
- `sources.json`: 키워드, 포함/제외어 설정
- `monitor_sources.json`: 자동 탐색 출처 목록과 중단한 출처(`retired_sources`)
- `seed_urls.txt`: 사람이 직접 등록하는 상세 페이지 URL 목록(1줄 = 공고 1건)
- `jobs.sqlite3`: 실행 후 생성되는 SQLite DB
- `sample_jobs.html`: 로컬 검증용 샘플 공고
- `secrets.env`: API 키(gitignore 대상). `secrets.env.example`을 복사해서 사용

사람인 API 키가 있으면 같은 명령에서 사람인 수집도 함께 실행됩니다.

```powershell
$env:SARAMIN_ACCESS_KEY="발급받은_access_key"
python collect_jobs.py --saramin-count 50
```

## 공개 사이트 (`build_site.py`)

수집한 DB로 공개용 정적 사이트를 만듭니다. 서버가 필요 없어서 Cloudflare Pages, GitHub Pages, Netlify 같은 정적 호스팅에 `site/` 폴더를 그대로 올리면 됩니다.

```powershell
python collect_jobs.py            # 수집
python build_site.py              # site/ 생성 (매번 새로 만듦)
python -m http.server 8765 --bind 127.0.0.1 -d site   # 미리보기: http://127.0.0.1:8765
```

만들어지는 것:

- `index.html`: 카카오맵 + 목록(마감순·최신순·가나다순·가까운순). 국내/해외/온라인, 신입 가능, 모의수업 있음 필터와 검색. 지도 핀과 목록이 연동되고, 가까운 핀은 묶음으로 표시돼요. 해외 탭은 나라별 카드.
- `jobs/<job_id>.html`: 공고마다 한 페이지(검색 노출용). 핵심 정보, 위치 지도, 공고 본문, 이메일 지원, 첨부파일 사본, 근처 공고, Google 채용 검색용 `JobPosting` 구조화 데이터.
- `demo.html`: 시강 교안 AI 체험 화면. **지금은 예시 교안만 보여 줘요(생성 기능은 아직 없음).**
- `sitemap.xml`, `robots.txt`

### 공고 상세: 한 페이지에 다, 출처는 숨김

이용자가 사이트를 떠나지 않도록 **공고 상세에는 원문·기관 링크와 출처 표시를 넣지 않습니다.** 지원에 필요한 정보는 모두 이 페이지 안에 있습니다.

1. **한눈에 보기**: 근무 기간·시간, 급여, 자격, 제출 서류, 접수 방법, 전형 일정, 문의 등 (Claude 추출)
2. **공고 내용** (`body_text`): Claude가 원문 게시글에서 메뉴·다른 공고 목록·게시판 이름을 빼고 공고 본문 전체를 정리한 글. `body_text`가 없으면 요약(`summary`)만 보여 줌
3. **이메일로 지원하기** (`apply_email`): 본문의 접수 이메일. 게시판 자체 주소는 제외
4. **공고문·지원 양식** (`attachments`): `mirror_attachments()`가 수집 때 파일을 `files/<job_id>/`로 내려받고, 사이트는 그 사본(`files/…`)을 내려받게 함. 사본이 없는 파일은 보여 주지 않음

화면에 나가기 전 한 번 더 거릅니다: `body_text`에서 모음 게시판 이름이 들어간 줄과 게시판 주소 링크는 빼고(`BOARD_NAMES`, `BOARD_HOSTS`), 기관 자체 링크(지원서 양식 등)와 이메일만 링크로 겁니다. `apply_url`/`original_url`은 수집·중복 판정용으로만 남습니다.

"지원하기"는 공고에 적힌 접수 방법을 보고 경우별 카드로 안내합니다(`apply_guide()`): 이메일(주소 + 복사 버튼), 온라인(구글·네이버 폼, 기관 지원 사이트 버튼), 우편·방문(기관 주소), 방법이 없으면 첨부 공고문 → 연락처 → 기관 문의 순. "방문 및 우편접수 불가" 같은 부정 문장은 제외합니다. 아래에 제출 서류와 문의처(전화 링크)를 붙입니다.

**예외: 진학프로.** 진학프로는 대학이 지원서를 받는 접수 시스템이라 그곳에서만 지원할 수 있습니다. 그래서 공고에 별도 지원 폼이 없으면 진학프로 공고 페이지를 "온라인 접수 페이지"로 링크합니다(`APPLY_SYSTEM_HOSTS`). 운영자가 출처 노출을 감수하기로 결정한 유일한 예외입니다.

공개 기준: `is_canonical = 1`(중복 묶음의 대표), `status`가 `rejected`가 아니고, 마감 전인 **국내·온라인** 공고. 검토자가 승인한 것만 올리려면 `--approved-only`.

**광고는 아직 없으므로 광고 자리를 그리지 않습니다.** 광고가 들어갈 위치를 미리 보려면 `--ad-slots`로 점선 상자를 표시합니다.

**목록 정렬**: 마감순(기본)·최신순(`posted_at`, 없으면 처음 수집한 날)·가나다순(기관명)·가까운순. 가까운순은 누를 때만 브라우저 위치 권한을 묻고, 위치는 그 화면에서 거리 계산과 지도 위 "내 위치" 점에만 씁니다(서버로 보내거나 저장하지 않음). 장소가 없는 온라인 공고는 맨 뒤로 갑니다. 위치 권한은 HTTPS(또는 localhost)에서만 동작합니다. 고른 정렬은 다음 방문에도 유지되지만 가까운순은 유지하지 않습니다(들어오자마자 위치를 묻지 않도록).

**저장·지원했어요**는 로그인 없이 브라우저(`localStorage`)에만 남습니다. 첫 화면의 "저장한 공고" 필터로 모아 보고, 목록에 "저장됨"·"지원함" 표시가 붙습니다. 이 브라우저에만 남는다는 안내를 공고 상세(버튼 아래)와 저장한 공고 필터에 보여 줍니다.

**저장 수 집계** (`serve.py`): 사이트를 `serve.py`로 띄우면 저장/저장 취소 때 브라우저가 `POST /api/save {job, client, on}`을 보내고 `stats.sqlite3`에 쌓입니다. `client`는 브라우저가 스스로 만든 무작위 값이라 개인 정보가 없고, 한 브라우저가 같은 공고를 여러 번 눌러도 1로 셉니다. `python -m http.server`로 띄우면 집계만 조용히 빠집니다.

```bash
python serve.py --port 8080 --bind 127.0.0.1   # 사이트 + 저장 집계
python serve.py --report                       # 공고별 저장 수 (now = 지금 저장 중인 브라우저, ever = 한 번이라도 저장)
```

**아직 공개하지 않은 서비스**(이력서·자소서 첨삭 `resume.html`, 시강 교안 AI `demo.html`)는 공개 빌드에서 메뉴·페이지·안내 배너가 모두 빠집니다. 서비스를 열 때 `python build_site.py --with-services`로 켜면 됩니다. 비공개 빌드에는 항상 나옵니다.

**해외 공고는 공개 사이트에 싣지 않습니다.** 수집은 계속하고, 운영자만 보는 비공개 빌드에서 봅니다.

```powershell
python build_site.py --private            # site_private/ 생성 (해외 포함, 나라별 보기)
python -m http.server 8765 --bind 127.0.0.1 -d site_private   # http://127.0.0.1:8765
```

`site_private/`는 gitignore 대상이고 **배포하면 안 됩니다.** 실수로 올라가도 검색에 걸리지 않도록 모든 페이지에 `noindex`, robots.txt에 `Disallow: /`를 넣고, 사이트맵과 광고 자리는 만들지 않습니다. 화면 맨 위에 "비공개 미리보기" 띠가 붙습니다.

안전장치: 공고의 모든 값은 다른 사이트에서 온 텍스트라서 HTML 이스케이프하고, 본문 속 링크는 `http(s)`만 연결합니다(`javascript:` 같은 링크는 버림). 첨부파일은 `숫자/숫자.확장자` 형태의 사본 경로만 씁니다.

설정(`secrets.env` 또는 환경변수):

| 키 | 용도 | 없으면 |
| --- | --- | --- |
| `KAKAO_JS_KEY` | 지도. **카카오 앱의 플랫폼 > Web에 사이트 도메인을 등록**해야 지도가 떠요(미리보기는 `http://127.0.0.1:8765`) | 지도 자리에 안내 문구 |
| `SITE_URL` | 예: `https://example.com`. canonical 링크, `sitemap.xml`, 구조화 데이터의 URL | 둘 다 생략 |
| `ALERT_ENDPOINT` | 알림 신청 폼이 `{email, filters}`를 JSON으로 POST할 주소 | **알림 받기를 모두 숨김** (헤더 버튼, 첫 화면 폼, 상세 옆 안내). 저장되지 않는 폼으로 알림을 약속하지 않기 위해서 |
| `ADSENSE_CLIENT` | 예: `ca-pub-…`. 넣으면 애드센스 자동 광고 스크립트를 넣어요(광고 위치는 구글이 정함) | 광고 없음 |

멘토링·전자책 링크는 `build_site.py`의 `SERVICE_LINKS`에 넣으면 해당 블록이 나타납니다(비어 있으면 숨김).

'새로 모았어요' 시각은 마지막 수집 실행(`collection_runs.finished_at`) 기준이고, D-day는 방문자가 페이지를 연 날짜(한국 시간) 기준으로 브라우저에서 다시 계산합니다.


## 지도 (카카오맵)

수집한 공고를 지도에 찍습니다. developers.kakao.com에서 앱을 하나 만들고 키 2개를 `secrets.env`에 넣습니다.

```
KAKAO_REST_API_KEY=REST_API_키
KAKAO_JS_KEY=JavaScript_키
```

- **REST API 키**: 수집이 끝난 뒤 좌표를 채우는 데 씁니다(서버에서만 사용).
- **JavaScript 키**: 브라우저가 지도를 그릴 때 씁니다. 카카오 앱 설정의 **플랫폼 > Web**에 `http://127.0.0.1:8765`를 등록해야 지도가 뜹니다.

좌표는 **기관명**을 카카오 로컬 키워드 검색에 넣어 얻습니다. 기관명으로 찾으면 그 주소의 시·도로 `location_text`를 덮어씁니다 — 페이지 본문에서 추측한 지역보다 정확하기 때문입니다. `가족센터`, `한국어학당`처럼 기관명이 일반 명칭뿐이면 다른 지역의 같은 이름 기관이 잡히므로 기관명 검색을 건너뜁니다(`GENERIC_INSTITUTION_NAMES`). 기관명 검색이 실패하거나 건너뛰면 `location_text`의 광역명을 시·도청 좌표로 대체합니다(대략적인 위치). 해외·온라인 공고는 지오코딩하지 않습니다. `--no-geocode`로 끌 수 있습니다.

조회 결과는 `geocode_cache` 테이블에 쌓이고, 못 찾은 이름도 캐시해서 같은 실패를 다시 요청하지 않습니다.

## 관리자 전용 테스트 사이트 (`/test`)

공개 사이트에 내보내기 전의 변경은 `/test` 아래에서 먼저 확인합니다. 지금 여기에만 있는 것:

- **큰 글씨** (`site_test_static/large.css`)
- **근무 후기**: 지도 말풍선의 주황색 "후기 보기"(공고 상세에도 있음) → `rating.html?org=…` 후기 결과(영역별 평균, 근무 조건, 후배에게 한마디) → "나도 후기 남기기" → `review.html?org=…`. 화면에는 "평가" 대신 "후기"라는 말을 씁니다. 평가 항목은 5개(급여·처우, 고용 안정성, 업무 강도, 사람과 분위기, 수업과 성장)에 문장 3개씩, 근무 조건 3개입니다(`review_items.py`). 첫 화면에서 방법을 고릅니다. **이야기로 남기기**(기본)는 심리테스트처럼 안내 → 근무하는 하루를 따라가는 장면 5개(교무실, 수업, 수업 후, 월급날, 학기말) → 후배에게 쪽지 순서로 진행되고, 보기 앞의 숫자 1~5가 곧 점수이며 오름차순으로 나옵니다. **점수로 바로 남기기**는 항목 → 문장 → 1~5점입니다. 어느 쪽이든 "잘 모르겠어요"로 건너뛰고 언제든 멈출 수 있으며, 보내기 전 **내 답 확인**에서 모든 문장 아래 1~5 체크 칸으로 점수를 바로 바꾸거나(같은 숫자를 다시 누르면 지움) 근무 조건·쪽지를 고칩니다. 보낸 뒤에는 결과 카드("당신이 기억하는 ○○는 …한 곳")가 나옵니다. 각 화면이 브라우저 기록이라 휴대폰 뒤로 가기는 한 단계씩 돌아갑니다.

```bash
python3 build_site.py          # 공개 사이트 → site/
python3 build_site.py --test   # 테스트 사이트 → site_test/ (noindex, 상단에 "테스트 페이지" 표시)
```

- `serve.py`가 `/test/…` 요청을 `site_test/`에서 내보냅니다. **`secrets.env`의 `ADMIN_PASSWORD`(사용자명 `ADMIN_USER`, 기본 `admin`)로 HTTP 기본 인증**을 거쳐야 하고, 비밀번호가 없으면 `/test`는 404입니다. 응답에는 `Cache-Control: no-store, private`를 붙여 Cloudflare 같은 공유 캐시에 남지 않게 합니다. 공개 `robots.txt`도 `/test/`를 막습니다.
- **법적 안전장치** (공개 전 변호사 검토 권장):
  - 문항과 보기는 모두 응답자의 **체감**("~라고 느꼈다", "만족했다")으로 씁니다. 법 위반을 암시하는 문항(임금 체불, 4대 보험, 퇴직금, 시수 쪼개기), 특정인(원장·주임) 평가, 학생의 국적·목적·비자 관련 문항은 두지 않습니다(테스트가 금지어를 검사). 결과 페이지는 "응답자 체감 평균"이라고 밝히고, 사이트가 사실을 보증하지 않는다고 적습니다.
  - 한 기관의 후기가 `PUBLIC_MIN`(5)개 이상 모여야 점수를 공개합니다(/test에서는 관리자 미리보기 가능). 작성 시기는 월 단위로만 저장하고 공개하지 않으며, 한마디는 날짜 없이 섞어서 보여 줍니다.
  - **한마디는 운영자가 승인해야 공개**됩니다: `python3 serve.py --pending`으로 보고 `--approve ID` / `--reject ID`. 게시 기준(실명·직함, 범죄·법 위반 단정, 학생 국적 비하 등)은 작성 화면과 정책 페이지에 있습니다.
  - **삭제·임시조치**: `review-policy.html`(후기 운영 정책)에 요청 창구(`secrets.env`의 `REVIEW_CONTACT`), 처리 기한(영업일 2일 내 임시조치, 최대 30일), 이의 제기 방법이 있습니다. 요청이 오면 `python3 serve.py --hide ID`로 가리고, 다시 공개할 때는 `--unhide ID`. ID는 `--reviews`에 나옵니다.
  - **작성자 서약**: 보내기 전 "직접 경험한 내용만 답했고, 사실과 다른 내용의 책임은 본인에게 있다"에 체크해야 하며, 서버도 서약 없는 후기는 받지 않습니다.
  - **IP를 남기지 않음**: `serve.py`의 접속 로그에서 IP를 뺐습니다. 다만 그 전의 systemd 저널과 Cloudflare 쪽 기록은 따로 정리·확인해야 합니다.
- 평가 문항은 `review_items.py` 한 곳에 있습니다. 빌드가 페이지에 넣고, 서버가 같은 목록으로 검사합니다. 평가자에 대한 정보(역할·경력·시기·IP)는 묻지도 저장하지도 않고, 날짜는 **월 단위**로만 남깁니다(`reviews.sqlite3`).
- 결과 페이지는 `GET /test/api/ratings?org=…`(문장별 합계·응답 수, 근무 조건 집계, 한마디와 작성 월)를 읽습니다. 모인 후기를 터미널에서 보려면 `python3 serve.py --reviews`
- **강사료 실수령 계산기** (`pay.html`): 시간당 강사료와 주당 시수로 한 달 실수령액을 프리랜서(3.3%)와 4대보험 근로자로 비교합니다. 계산은 `site_test_static/pay.js` 한 곳에 있고(`tests/test_pay.py`가 node로 검사), 보험료율은 파일 맨 위 `RATES`에 있어 **매년 1월·7월에 확인**해야 합니다. 소득세는 간이세액표 산식을 1인 가구로 근사한 값입니다. 공고에 "시간당 ○○원"이 있으면 공고 상세의 강의료 옆에 `실수령 계산` 링크가 붙고 값이 채워집니다.
- 큰 글씨를 공개 사이트에 반영할 때는 `large.css`의 규칙을 `site_static/styles.css`에 합치고 `page()`의 `large.css` 링크를 없애면 됩니다.
